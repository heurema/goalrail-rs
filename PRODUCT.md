# Product

## Register

brand

## Users

Coding agents receive the site as the canonical starting point. Their human
operators use the same page to understand what Goalrail can do now and whether
the project is actively moving.

## Product Purpose

Goalrail helps coding agents work inside explicit authority and return
verifiable evidence. The site makes installation discoverable to agents and
keeps the public promise aligned with repository truth.

## Brand Personality

Calm, precise, alive.

## Anti-references

- Dense terminal dashboards and long technical ledgers.
- Generic SaaS card grids, gradients, and decorative metrics.
- Empty luxury/editorial heroes that hide what the product actually does.
- Static roadmaps that drift away from the repository.

## Design Principles

- Agent-first: the core message and links work without client-side execution.
- Show the handoff: one purposeful motion explains site to agent to evidence.
- Repository-current: public status names only checked-in capabilities.
- One-screen clarity: one promise, one primary action, one current-state line.
- Honest progress: implemented, active, and pending are never conflated.

## Accessibility & Inclusion

Dark-first for comfortable evening use, WCAG AA contrast for text and controls,
full keyboard and touch access, and an instant non-animated state when reduced
motion is requested.
